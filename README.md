# 🏛️ Informatics & IT Fundamentals (ETU "LETI")

This repository contains a comprehensive collection of 20 practical assignments completed during my studies at **Saint Petersburg Electrotechnical University (ETU "LETI")**. 

As a student of **"Software and Hardware Solutions for AI"**, these works represent my foundation in computer architecture, low-level programming, and system administration.

---

## 📂 Modules & Key Topics

### 🔹 Module 1: Computer Science Basics (`Informatics_Basics/`)
*Focus: Operating systems foundations and algorithmic logic.*
* **OS Administration:** Unix/Linux environment, file system permissions, and **Bourne Shell (sh)** scripting.
* **Programming Foundations:** Core algorithms using **Pascal** (data types, variables, loops, and branching logic).
* **CLI Experience:** Work with terminal-based text editors (Vim) and compilers (FPC).

### 🔹 Module 2: IT & System Architecture (`Computer_Architecture_and_IT/`)
*Focus: Hardware-software interaction and RISC-V architecture.*
* **Instruction Set Architecture:** Deep dive into **RISC-V** (RV32I) using the **RARS** emulator.
* **Low-Level Programming:** Register files, addressing modes (immediate, base, relative), and macro-assemblers.
* **Mathematical Co-processor:** Floating Point Unit (FPU) operations and **IEEE 754** floating-point standard.
* **High-Performance Computing:** Writing optimized assembly code for complex mathematical calculations (Taylor series, vector operations).

---

## 🚀 Relevancy to AI Systems
Understanding **RISC-V** and **FPU** operations is essential for my professional profile. It provides the necessary knowledge to optimize neural network inference on specialized hardware and develop efficient AI accelerators.
